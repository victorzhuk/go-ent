# Fuzzing

Fuzz testing with Go 1.18+ native fuzzing.

## Quick Reference

| Feature | Example |
|---------|---------|
| **Basic fuzzing** | `func FuzzParse(f *testing.F)` |
| **Seed corpus** | `f.Add("valid")`, `f.Add(42, "input")` |
| **Multiple seeds** | Add calls + `testdata/fuzz/FuzzName/` |
| **Complex types** | Fuzz primitives, build structs in function |
| **Run locally** | `go test -fuzz=FuzzParse -fuzztime=30s` |
| **Run in CI** | `go test -fuzz=. -fuzztime=10s` |
| **Coverage** | `go test -fuzz=FuzzParse -fuzztime=1m -coverprofile=fuzz.out` |
| **Corpus location** | `testdata/fuzz/<FuzzName>/<hash>` |

```go
func FuzzParse(f *testing.F) {
    // Seed corpus
    f.Add("valid input")
    f.Add("")
    f.Add("extreme-case-12345")

    f.Fuzz(func(t *testing.T, input string) {
        result, err := Parse(input)
        if err != nil {
            return  // Expected for invalid input
        }
        // Validate invariants
        if result == "" {
            t.Error("empty result from valid parse")
        }
    })
}

// Run: go test -fuzz=FuzzParse -fuzztime=30s
```

## Multiple Seed Corpus

Provide diverse starting points for the fuzzer.

```go
func FuzzJSONParse(f *testing.F) {
    // Multiple seed inputs
    f.Add(`{"id":1,"name":"test"}`)
    f.Add(`{}`)
    f.Add(`{"nested":{"field":"value"}}`)
    f.Add(`[]`)  // Invalid for this parser
    f.Add(`null`)

    f.Fuzz(func(t *testing.T, data string) {
        var result map[string]interface{}
        err := json.Unmarshal([]byte(data), &result)
        if err != nil {
            return  // Expected for malformed JSON
        }
        // Validate parsed data
        if result == nil {
            t.Error("null result after successful parse")
        }
    })
}
```

**Corpus directory structure:**

```
testdata/fuzz/FuzzJSONParse/
├── 1a2b3c4d5e6f7890  # Auto-generated by fuzzer
├── a1b2c3d4e5f6g7h8  # Another finding
└── seed_custom      # Manual seed (named file)
```

**Adding corpus files manually:**

```bash
# Create corpus directory
mkdir -p testdata/fuzz/FuzzJSONParse

# Add seed (content must match fuzz function signature)
echo -n '{"malicious":"payload"}' > testdata/fuzz/FuzzJSONParse/exploit_case
```

## Complex Types

Fuzz functions accept primitives only. Build complex types inside.

```go
// Good: Fuzz primitives, build struct
func FuzzCreateOrder(f *testing.F) {
    f.Add(int64(100), "USD", "user-123")
    f.Add(int64(0), "", "")
    f.Add(int64(-50), "EUR", "admin")

    f.Fuzz(func(t *testing.T, amount int64, currency, userID string) {
        order := domain.Order{
            ID:       uuid.Must(uuid.NewV7()),
            Amount:   decimal.NewFromInt(amount),
            Currency: currency,
            UserID:   userID,
        }

        err := order.Validate()
        if err != nil {
            return  // Expected for invalid combinations
        }

        // Test invariants on valid orders
        if order.Amount.IsNegative() {
            t.Error("validated order has negative amount")
        }
        if order.Currency == "" {
            t.Error("validated order has empty currency")
        }
    })
}
```

**Fuzzing JSON marshaling:**

```go
func FuzzUserJSON(f *testing.F) {
    f.Add("john@example.com", "John Doe", int64(1234567890))

    f.Fuzz(func(t *testing.T, email, name string, created int64) {
        user := User{
            Email:     email,
            Name:      name,
            CreatedAt: time.Unix(created, 0),
        }

        data, err := json.Marshal(user)
        if err != nil {
            t.Fatalf("marshal failed: %v", err)  // Should never happen
        }

        var decoded User
        if err := json.Unmarshal(data, &decoded); err != nil {
            t.Fatalf("unmarshal failed: %v", err)
        }

        // Validate round-trip
        if decoded.Email != user.Email {
            t.Errorf("email mismatch: got %q, want %q", decoded.Email, user.Email)
        }
    })
}
```

## CI Integration

Run fuzzing in CI with time limits to catch regressions.

**Makefile:**

```makefile
.PHONY: fuzz
fuzz:
	go test -fuzz=. -fuzztime=60s ./...

.PHONY: fuzz-ci
fuzz-ci:
	go test -fuzz=. -fuzztime=10s -parallel=4 ./...
```

**GitHub Actions:**

```yaml
- name: Fuzz tests
  run: go test -fuzz=. -fuzztime=30s -parallel=2 ./...
  timeout-minutes: 5

- name: Commit new corpus
  if: failure()
  run: |
    git config user.name "Fuzzer Bot"
    git add testdata/fuzz
    git commit -m "Add fuzz corpus from CI failure"
    git push
```

**Storing corpus in git:**

```bash
# Commit interesting findings
git add testdata/fuzz/FuzzParse/
git commit -m "Add fuzz corpus for parser edge cases"
```

**Parallel fuzzing:**

```bash
# Run multiple fuzzers in parallel (CI)
go test -fuzz=FuzzA -fuzztime=10s & \
go test -fuzz=FuzzB -fuzztime=10s & \
wait
```

## Crash Reproduction

When fuzzing finds a crash, it saves the input to the corpus.

**Crash example:**

```
--- FAIL: FuzzParse (0.12s)
    --- FAIL: FuzzParse (0.00s)
        parse_test.go:15: unexpected panic: runtime error: index out of range

    Failing input written to testdata/fuzz/FuzzParse/a1b2c3d4e5f6g7h8
    To re-run:
    go test -run=FuzzParse/a1b2c3d4e5f6g7h8
```

**Reproducing:**

```bash
# Re-run specific failing input
go test -run=FuzzParse/a1b2c3d4e5f6g7h8

# Or use as table-driven test case
cat testdata/fuzz/FuzzParse/a1b2c3d4e5f6g7h8
```

**Converting to regression test:**

```go
func TestParseRegression(t *testing.T) {
    // From testdata/fuzz/FuzzParse/a1b2c3d4e5f6g7h8
    input := "fuzz-discovered-crash-input"

    result, err := Parse(input)
    if err != nil {
        t.Logf("expected error: %v", err)
        return
    }

    if result == "" {
        t.Error("empty result")
    }
}
```

## Coverage

Track which code paths fuzzing exercises.

```bash
# Generate coverage profile
go test -fuzz=FuzzParse -fuzztime=1m -coverprofile=fuzz.out

# View coverage
go tool cover -func=fuzz.out
go tool cover -html=fuzz.out

# Find uncovered code
go tool cover -func=fuzz.out | grep -v "100.0%"
```

**Comparing coverage:**

```bash
# Baseline coverage
go test -coverprofile=baseline.out ./...

# Fuzz coverage
go test -fuzz=. -fuzztime=30s -coverprofile=fuzz.out ./...

# Diff
go tool cover -func=baseline.out > baseline.txt
go tool cover -func=fuzz.out > fuzz.txt
diff baseline.txt fuzz.txt
```

## Common Mistakes

| Mistake | Problem | Solution |
|---------|---------|----------|
| **Insufficient seed corpus** | Fuzzer explores narrow input space | Add diverse `f.Add()` calls and corpus files |
| **Not checking errors** | Crashes on expected invalid input | Return early for expected errors |
| **Fuzzing wrong layer** | Fuzzing HTTP handlers instead of domain | Fuzz domain logic, not transport |
| **Ignoring panics** | Panic = crash = test failure | Fix panics or document why impossible |
| **Slow fuzz functions** | Low iterations/sec, poor coverage | Optimize hot paths, avoid I/O |
| **No invariant checks** | Fuzzer finds nothing useful | Add assertions for business rules |
| **Determinism issues** | Same input, different result | Remove randomness (use input as seed) |

**Example: Fixing slow fuzz function**

```go
// Bad: Slow (DB calls)
func FuzzCreateUser(f *testing.F) {
    f.Add("test@example.com")
    f.Fuzz(func(t *testing.T, email string) {
        db := setupDB(t)  // SLOW
        defer db.Close()

        CreateUser(db, email)
    })
}

// Good: Fast (pure logic)
func FuzzValidateEmail(f *testing.F) {
    f.Add("test@example.com")
    f.Fuzz(func(t *testing.T, email string) {
        err := ValidateEmail(email)  // Pure function
        if err != nil {
            return
        }
        if !strings.Contains(email, "@") {
            t.Error("valid email missing @")
        }
    })
}
```
