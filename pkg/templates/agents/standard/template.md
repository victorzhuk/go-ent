# Standard Agent Template

This template creates a standard agent with customizable configuration.

## Files Generated

- `agent.yaml` - Agent metadata and configuration
- `prompt.md` - Agent's system prompt and guidelines

## Template Variables

- `${AGENT_NAME}` - Name of the agent
- `${DESCRIPTION}` - Agent description
- `${MODEL}` - Model tier (haiku/main/opus)
- `${ROLE}` - Agent role (execution/planning/review/research)
- `${COMPLEXITY}` - Task complexity level
- `${SKILLS}` - Comma-separated skill names
- `${TOOLS}` - Comma-separated tool names
